## 1. Overview

Infraestructura de verificación. Gestión individual confirmada por el usuario; planificación local Markdown en ausencia de otra autoridad declarada. Dos iniciativas: la infraestructura tiene trabajo propio de aprovisionamiento, datos y ejecución y puede verificarse antes de la aplicación. El usuario ha autorizado implementarla; no se presume infraestructura comercial ni capacidad adicional.

La separación de infraestructura ya fue confirmada y se mantiene: WP-010 amplía PRJ-002 con un entorno Windows aislado para instalación antigua, actualizaciones, servicios y reinicios. No se presupone que el entorno Compose de WP-001 permita ensayar el ciclo de servicios Windows, ni se crea otra iniciativa por el tamaño del equipo. El equipo de prueba concreto, sus permisos y el método de aislamiento siguen pendientes; no se autoriza compra ni modificación del servidor del cliente mediante este plan.
