## 6. Acceptance and Dependencies

- Cobertura prevista: TEST-007, TEST-008, TEST-015, TEST-016, TEST-018 y TEST-019; se requiere evidencia real antes de cierre.
- Otro usuario autenticado no obtiene datos ni modifica persistencia. No autorizar por nombre o correo; aplicar configuración de emisor/sujeto después de validar el token.
- Identidad técnica real pendiente de configurar. Preparar pruebas con dos identidades sintéticas del mismo emisor; no copiar secretos ni datos de CRM.
- Coordinar WP-002 y WP-005 para cubrir todas las rutas y adjuntos. HTTPS queda condicionado a disponer de entorno de validación; no se declara publicación autorizada.
