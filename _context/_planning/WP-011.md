## 1. Overview

Preparar una instalación Docker nueva en Windows con API, Keycloak y PostgreSQL persistentes. La API se publica en GHCR y una tarea de Windows aplica nuevas imágenes cuando Docker Desktop está disponible. No migra ni modifica la instalación Windows nativa actual. La publicación de una etiqueta real y el despliegue en el equipo del cliente requieren sus propias comprobaciones.

## 6. Acceptance and Dependencies

El código, la compilación local y la validación estática no cierran TEST-039 a TEST-042. Se necesitan pruebas integradas en el Windows con Docker Desktop de destino, identidad real de ensayo y portal compatible antes de entregar al cliente. Los cambios mayores de PostgreSQL y Keycloak quedan fuera del canal automático de API. Una tarea que no puede acceder al daemon Docker no actualiza hasta que la sesión y Docker Desktop vuelvan a estar disponibles.
